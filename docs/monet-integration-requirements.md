# Monet 宿主接入需求 — 截图/录制产物出口定制

> 需求方：Monet（dm-tapnow）画布，经 `input-3d-director` 节点嵌入导演台。
> 状态：待评审。日期：2026-09-02。

## 背景

Monet 画布中的导演台节点，用户在导演台内编排场景后，截图/录制产物的去向是 **Monet 画布**（经宿主通道落为 `input-image` / `input-video` 节点，供下游生成节点消费），而非本地下载。

产物回传通道已就绪（`host.reportCapture` 的 blobUrl 宿主已接：转 File → 上传 OSS → 落画布节点）。本次需求只涉及 **产物出口的 UI 语义与扩展位**。

## 需求清单

### R1 截图/录制按钮文案可自定义

**现状**：顶部工具栏的截图、录制按钮为内置固定语义（图标 + 通用文案/ tooltip）。

**问题**：Monet 用户在导演台里点击截图时，产物不是"下载到本地"而是"上传到画布成为节点"。固定文案无法表达产物去向，用户预期错位（以为存到本地，实际出现在画布）。

**期望**：截图/录制按钮的文案（label / tooltip）支持宿主自定义。例如 Monet 场景下显示「截图到画布」「录制到画布」。

**建议形态**（供参考，不强制）：

```tsx
<DirectorDesk
    actions={{
        captureImage: { label: "截图到画布", tooltip: "截图并添加到画布" },
        captureVideo: { label: "录制到画布", tooltip: "录制并添加到画布" },
    }}
/>
```

**验收**：
- 传入自定义文案后，按钮可见文本与 tooltip 均替换
- 不传时保持现有默认文案（向后兼容）

### R2 工具栏外部接入按钮位

**现状**：工具栏按钮集由导演台内置，宿主无法追加自有动作。

**问题**：Monet 侧除「截图到画布」「录制到画布」外，还有宿主特有动作需要进入导演台工具栏，例如：
- 场景复用类：「从画布导入模型」（把 Monet 画布的 3D 资产直接放进导演台场景，经 `host.onImportModel` 通道）
- 后续可能的「保存模板」「分享给协作人」等宿主业务动作

这些动作是宿主业务语义，不应进入组件方内置按钮集，但需要一个固定的、视觉一致的落位。

**期望**：工具栏提供外部按钮扩展位，宿主注入自定义按钮（图标 + 文案 + 点击回调），与内置截图/录制按钮同区呈现、视觉风格一致（尺寸/悬浮态/禁用态跟随工具栏规范）。

**建议形态**（供参考，不强制）：

```tsx
<DirectorDesk
    toolbarExtensions={[
        {
            key: "import-from-canvas",
            icon: <ImportIcon />,
            label: "从画布导入",
            onClick: () => { /* 宿主逻辑 */ },
        },
    ]}
/>
```

**验收**：
- 扩展按钮渲染在工具栏内置动作区（截图/录制附近），风格与内置按钮一致
- 点击回调由宿主接管（组件方不拦截、不附加默认行为）
- 支持禁用态（如「从画布导入」在无可导入资产时禁用）
- 扩展位为空时不占位、不影响现有布局

## 边界说明

- 本需求只涉及 UI 出口层；产物数据通道（reportCapture / onImportModel）与命令层均已具备，不在本需求范围
- 截图/录制的**能力触发**本身（capture / recordVideo）已由组件方提供，本需求只要求按钮的文案与宿主动作的落位

## 优先级

R1、R2 均为 Monet 接入的必要项（P1）。R2 的「从画布导入模型」按钮依赖 `onImportModel` 宿主侧接线（Monet 侧另行排期），扩展位机制本身不阻塞。
