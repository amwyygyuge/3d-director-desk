3D Director Desk · 布局提案

先决定用户在什么位置做什么事

三套布局都移除了“布景 / 运镜 / 成片”阶段跳转。顶部中间固定为视口模式；右上固定为撤销、重做与更多操作；时间轴始终只负责镜头。选择后再把对应布局落进 React。

推荐作为默认编辑态

A. 导演驾驶舱

左边场景与机位身份导航，中央最大化视口，右边只显示当前片段的上下文属性，底部全宽镜头时间轴。最适合连续布景、构图、路径和切镜。

打开布局 A

B. 聚焦画布

为路径编辑和构图让出最大中央空间。左侧只回答“编辑谁”，右侧回答“怎么编辑”，底部时间轴只覆盖主要工作区域。

打开布局 B

C. 审片室

Program 预览优先，左边用镜头板组织切换，右边显示叙事、构图和复核信息。适合 Review，不适合作为默认创作态。

打开布局 C
